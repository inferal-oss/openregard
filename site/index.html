Your profiles.
A shared preference.

No preset profiles. No imposed palette. Just the tools to offer a thoughtful choice.

01 / DEFINE

Make it yours.

Name your profiles, translate the labels, choose the order. Use your own CSS hooks or pass CSS custom properties. Every profile is configurable.

02 / REMEMBER

Carry it along.

Keep controls, pages and same-origin tabs in sync. Include the app and the docs. If storage is unavailable, the current page still works.

03 / RESPECT

Keep it native.

A real select. A clear label. Visible keyboard focus. A framework-independent core, with React there when you want it.

your-site.jsVanilla / TypeScript 
import { createRegard, mountWidget }
  from 'openregard';

const regard = createRegard({
  version: 1,
  defaultProfile: 'original',
  storageKey: 'my-site-view',
  controlLabel: 'Choose your view',
  profiles: [
    { id: 'original', label: 'Original' },
    { id: 'roomy', label: 'Room to read',
      tokens: { '--reading-size': '125%' } }
  ]
});

mountWidget(container, regard);

Your CSS uses var(--reading-size, 100%). Open Regard handles the preference.
