02 / WCAG-informed presentation

Connect tokens to your CSS.

The Vision profile uses the text-spacing override values from WCAG 1.4.12. Your CSS consumes the line height, paragraph, letter and word spacing tokens. These values are an override recipe, not a required default design.

  1. Compose the optional presets into a profile’s tokens.
  2. Use the custom properties in headings, body text, navigation and controls.
  3. Check the real page at 320 CSS pixels, with enlarged text and your users’ settings.

Vision + High Contrast also uses paired palette tokens whose solid text pairs exceed 7:1. Other colors, imagery and component states still need their own checks.

03 / WHATWG HTML integration

Keep the native behavior.

The widget uses a real label, select and options. The native-controls recipe uses platform color tokens; it cannot create semantics. Use labeled inputs, real links and buttons in the surrounding page as well.

A token preset does not establish accessibility conformance. See the standards and token preset guide for the distinction and sources.
